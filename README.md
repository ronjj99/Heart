# ❤️ Heart from Lines

A simple heart animation created using HTML and JavaScript. It draws a heart using thousands of red lines on a black background.

## ✨ Features
- ❤️ Animated heart made of red lines
- 🖤 Black background
- 🖱️ Click anywhere to replay the animation
- 📱 Responsive screen size

## 🛠️ Built With
- HTML
- JavaScript

## 📂 Project Structure

```text
Heart-from-Lines/
├── index.html
└── code.js
```

## 🚀 How to Run
1. Download or clone this repository.
2. Keep `index.html` and `code.js` in the same folder.
3. Open `index.html` in your browser.
4. Click anywhere on the screen to replay the animation.

## 💡 About the Project

This project uses JavaScript and the HTML Canvas API to draw a heart shape through animated red lines. It is a simple creative coding project made for fun and practice.
